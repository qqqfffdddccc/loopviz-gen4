# loopviz-gen4

Репозиторий бригады 4 по дисциплине «Технология разработки программного обеспечения». Две сдачи лежат в разных ветках.

## scrum

Настольное приложение LoopViz. Из короткого музыкального лупа оно собирает вертикальный ролик, в котором картинка реагирует на звук. Ветка содержит историю разработки LoopViz. Дальнейшие спринты коммитятся сюда, в сообщении коммита указывается номер спринта.

## waterfall

Один коммит с каскадной сдачей от 28 октября 2026 года. В нём отчёт и сайт CLOUD: `app/index.html`, `app/server.py`, `app/Запустить_Mac.command`. CLOUD открывается в браузере через локальный сервер. Это отдельная программа, у ветки своя история.

## main

На этой ветке лежит данное описание. Код LoopViz в ней совпадает с веткой `scrum` до коммита с этим файлом. Для проверки Scrum смотрите ветку `scrum`, для проверки Waterfall смотрите ветку `waterfall`.
